# Worker Finder — 设计规范

> 参考 [flipped-editor](https://flipped-editor.pages.dev/) 的杂志化编辑风格，整体追求**克制、安静、有呼吸感**的阅读体验。

---

## 1. 设计理念

- **杂志编辑风**：像翻阅一本精心排版的杂志，内容永远是主角，UI 退到背景里
- **少即是多**：不堆砌功能入口，每个页面只做一件事
- **呼吸感**：大量留白，让眼睛有休息空间

---

## 2. 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 页面背景 | `#faf9f6` | 暖白底，比纯白柔和，不刺眼 |
| 卡片 / 面板背景 | `#ffffff` | 纯白，用于导入区、分析区等操作面板 |
| 主文字 | `#2c2c2c` | 正文，接近纯黑但不生硬 |
| 次级文字 | `#6b6b6b` | 辅助说明、标签、提示 |
| 弱化文字 | `#999999` | 占位符、禁用态 |
| 主强调色 | `#c45a3c` | 按钮、链接、进度条，暖调赤陶色，有温度但不刺眼 |
| 主强调色 hover | `#a8482e` | 按钮悬停 |
| 边框 / 分割线 | `#e8e4df` | 极淡的暖灰，分割但不割裂 |
| 成功 / 完成 | `#5a8f6c` | 完成状态、成功提示 |
| 错误 / 警告 | `#c45a3c` | 与主色共用，统一暖调 |

## 3. 字体系统

| 层级 | 字体 | 字号 | 字重 | 用途 |
|---|---|---|---|---|
| H1 | Noto Serif SC | 28px | 700 | 页面主标题 |
| H2 | Noto Serif SC | 20px | 600 | 区域标题（如"导入简历"） |
| H3 | Noto Serif SC | 16px | 500 | 小标题 |
| Body | Noto Sans SC | 15px | 400 | 正文、段落 |
| Body-EN | Inter / Georgia | 15px | 400 | 英文职位描述或简历内容 |
| Caption | Noto Sans SC | 13px | 400 | 说明文字、进度、标签 |
| Code | JetBrains Mono | 13px | 400 | 技术字段、结构化信息等 |

**字体回退方案**：
```
--font-serif: 'Noto Serif SC', 'Source Han Serif SC', 'Songti SC', Georgia, serif;
--font-sans:  'Noto Sans SC', 'Source Han Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif;
--font-mono:  'JetBrains Mono', 'SF Mono', 'Cascadia Code', monospace;
```

## 4. 间距系统

基于 4px 栅格，核心间距：

| 标记 | 值 | 用途 |
|---|---|---|
| xs | 4px | 紧密元素间距 |
| sm | 8px | 同类元素间距 |
| md | 16px | 区域内元素间距 |
| lg | 24px | 区块内边距 |
| xl | 32px | 区块间距 |
| 2xl | 48px | 大区块间距 |
| 3xl | 64px | 页面级留白 |

**特殊规则**：
- 页面内容最大宽度：`720px`，居中显示
- 预览区内容最大宽度：`680px`
- 能力 / 经历区块之间间距：`24px`
- 标签、说明与正文之间：`8px`

---

## 5. 圆角与阴影

| 元素 | 圆角 | 阴影 |
|---|---|---|
| 卡片 / 面板 | `8px` | `0 1px 3px rgba(0,0,0,0.04)` |
| 按钮 | `6px` | 无 |
| 输入框 | `6px` | 无，使用 `border` |
| 上传拖拽区 | `8px` | 无，使用虚线边框 `dashed` |

原则：**阴影仅用于抬升必要层级，绝不滥用**。

## 7. 组件规范

### 7.1 上传区域

- 虚线边框，`border: 1.5px dashed #d4cfc9`
- 背景 `#faf9f6`，hover 时 `#f3f0eb`
- 图标 + 提示文字居中
- 导入成功后切换为文件信息条（文件名 + 内容摘要 + 重选按钮）

### 7.2 输入框

- 无背景色，底部单线边框 `border-bottom: 1.5px solid #e8e4df`
- focus 时边框变为 `#c45a3c`
- label 在上方，字号 13px，颜色 `#6b6b6b`
- placeholder 颜色 `#999999`

### 7.3 按钮

- 主按钮：背景 `#c45a3c`，文字白色，hover 时 `#a8482e`
- 次按钮 / 操作按钮：背景透明，边框 `1.5px solid #e8e4df`，文字 `#2c2c2c`，hover 时边框 `#c45a3c`
- 高度 `40px`，内边距 `0 24px`
- 字号 `14px`，字重 `500`

### 7.4 进度条

- 高度 `4px`，背景 `#e8e4df`，填充色 `#c45a3c`
- 圆角 `2px`
- 右侧跟文字说明（如 "匹配度 80%"），字号 13px

### 7.5 能力与经历区块

- 职位描述或简历原文：字体 `Georgia`，字号 `15px`，行高 `1.8`，颜色 `#2c2c2c`
- 分析结果与建议：字体 `Noto Sans SC`，字号 `15px`，行高 `1.8`，颜色 `#2c2c2c`
- 原文与分析结果间距：`8px`
- 每个能力 / 经历区块之间间距：`24px`
- 编辑态：经历内容可点击编辑，出现 textarea，失焦保存

---

## 8. 动效

- 过渡统一使用 `transition: all 0.2s ease`
- 按钮 hover：颜色渐变 + 轻微上浮 `transform: translateY(-1px)`
- 卡片出现：`fadeIn` + `translateY(8px) → translateY(0)`
- 进度条：`transition: width 0.3s ease`
- 不做夸张动画，保持安静克制

---

## 9. 响应式

- 桌面端（≥ 768px）：最大宽度 720px 居中，完整布局
- 移动端（< 768px）：全宽，内边距 16px，按钮全宽排列
